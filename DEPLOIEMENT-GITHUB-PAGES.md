## ⚙️ **ÉTAPE 4 : ACTIVER GITHUB PAGES**

### 🔧 Configuration :
1. **Dans votre repository**, cliquez onglet **"Settings"**
2. **Menu gauche**, descendez jusqu'à **"Pages"**
3. **Source** : Sélectionnez **"Deploy from a branch"**
4. **Branch** : Sélectionnez **"main"**
5. **Folder** : Laissez **"/ (root)"**
6. **Cliquez** "Save"

### ✨ **Confirmation :**
- GitHub affiche : "Your site is published at https://votre-nom.github.io/magazine-a-savoir"
- ⏱️ **Délai** : 5-10 minutes pour la première mise en ligne

## 🆘 **RÉSOLUTION DE PROBLÈMES**

### ❌ **Site ne s'affiche pas :**
- **Attendez 10 minutes** après activation
- **Vérifiez** que le fichier s'appelle exactement `index.html`
- **Settings → Pages** : Vérifiez source = "main"

### ❌ **Images ne chargent pas :**
- **Vérifiez** le dossier `images/` existe
- **Noms de fichiers** : respectent exactement ceux du HTML
- **Pas d'espaces** ou caractères spéciaux dans noms

### ❌ **Erreur 404 :**
- **Repository public** ? (obligatoire pour gratuit)
- **Fichier index.html** à la racine du projet
- **Attendre** la propagation DNS (10-15 minutes)
