# 🚀 Déploiement Magazine "A SAVOIR" sur GitHub Pages

## ⏰ Temps requis : 10 minutes

Votre magazine **"A SAVOIR"** est prêt à être déployé gratuitement sur GitHub Pages !

---

## 📋 Étapes de déploiement

### 1️⃣ Créer un compte GitHub (si vous n'en avez pas)
- Allez sur [github.com](https://github.com)
- Cliquez sur **"Sign up"**
- Choisissez un nom d'utilisateur (ex: `votre-nom`)

### 2️⃣ Créer un nouveau dépôt
- Cliquez sur le bouton **"New"** (vert)
- Nom du dépôt : `magazine-a-savoir`
- ✅ Cochez **"Add a README file"**
- Cliquez sur **"Create repository"**

### 3️⃣ Télécharger vos fichiers
Vous devez uploader ces fichiers depuis votre projet :
- ✅ **index.html** (votre magazine principal)
- ✅ **README.md** (documentation)

**Comment uploader :**
1. Cliquez sur **"uploading an existing file"**
2. Glissez-déposez `index.html`
3. Écrivez : "Ajouter le magazine A SAVOIR"
4. Cliquez **"Commit changes"**

### 4️⃣ Activer GitHub Pages
1. Dans votre dépôt, cliquez sur **"Settings"** (onglet)
2. Descendez jusqu'à **"Pages"** (menu gauche)
3. Source : sélectionnez **"Deploy from a branch"**
4. Branch : sélectionnez **"main"**
5. Cliquez **"Save"**

### 5️⃣ Accéder à votre magazine
🎉 **Votre URL sera :** `https://votre-nom.github.io/magazine-a-savoir`

⏳ **Délai :** 5-10 minutes pour que le site soit en ligne

## 🆘 Problèmes courants

### ❌ Le site ne s'affiche pas
- **Attendez 10 minutes** après activation
- Vérifiez que le fichier s'appelle bien `index.html`
- Regardez l'onglet "Actions" pour voir si le déploiement est terminé

### ❌ Erreur 404
- Le nom du fichier doit être exactement `index.html`
- Vérifiez dans Settings > Pages que la source est "main"

### ❌ Le contenu ne s'affiche pas
- Votre fichier `index.html` fonctionne déjà localement
- Sur GitHub Pages, cela fonctionnera de la même manière

## 🔄 Mettre à jour votre magazine

Pour ajouter de nouveaux articles :
1. Modifiez le fichier `index.html` localement
2. Sur GitHub, cliquez sur le fichier `index.html`
3. Cliquez sur l'icône crayon (Edit)
4. Collez le nouveau contenu
5. Cliquez **"Commit changes"**

Le site se mettra à jour automatiquement en quelques minutes !
