## 🎯 **Mise en Ligne en 3 Étapes (10 minutes)**

### **Étape 1 : Créer un Compte GitHub (2 minutes)**
1. Allez sur **github.com**
2. Cliquez **"Sign up"**
3. Choisissez un nom d'utilisateur (ex: `votrenom-magazine`)
4. Confirmer l'email

### **Étape 2 : Créer le Repository (3 minutes)**
1. Cliquez le **"+" vert** en haut à droite
2. **"New repository"**
3. Nom : `magazine` ou `a-savoir`
4. ✅ Cochez **"Public"**
5. ✅ Cochez **"Add a README file"**
6. Cliquez **"Create repository"**

### **Étape 3 : Upload et Publication (5 minutes)**
1. Cliquez **"Add file" > "Upload files"**
2. **Glissez-déposez** le fichier `magazine-simple-gratuit.html`
3. **Renommez-le** en `index.html` (important !)
4. Écrivez dans "Commit" : `Premier magazine`
5. Cliquez **"Commit changes"**

6. Allez dans **"Settings"** (onglet du repo)
7. Scroll jusqu'à **"Pages"** (menu gauche)
8. Source : **"Deploy from branch"**
9. Branch : **"main"**
10. Cliquez **"Save"**

### **🎉 TERMINÉ ! Votre URL :**
```
https://votrenom-magazine.github.io/magazine/
```

## ✏️ **Personnalisation Facile**

### **Changer le Titre :**
```html
<h1 class="title">📰 VOTRE TITRE</h1>
<p class="subtitle">Votre description</p>
```

### **Ajouter un Article :**
```html
<article class="article">
    <h3>🚀 Votre Titre d'Article</h3>
    <div class="meta">📅 Aujourd'hui • ⏱️ 3 min • 👁️ 1.2k vues</div>
    <p>Votre contenu ici avec <span class="highlight">texte en surbrillance</span>.</p>
</article>
```

### **Modifier les Couleurs :**
```css
/* Dans la section <style> */
background: linear-gradient(135deg, #VOTRE-COULEUR1, #VOTRE-COULEUR2);
```
